# Autonomous Business System

Design of the AUTONOMOUS BUSINESS SYSTEM product page
for AI Business Systems.

## Deliverables

- Desktop design, 1440 px
- Mobile design, 390 px
- Editable Figma source
- Full-page PNG previews
- Used visual assets
- Responsive behaviour and action descriptions
- Font and licence information

## Software

Created in Figma.

## Files

- `previews/` — desktop and mobile PNG previews
- `sources/` — editable Figma source
- `assets/` — images used in the design
- `fonts-and-licenses/` — font and licence information
- `responsive-and-actions/` — responsive behaviour and links

## How to open

Import `sources/autonomous-business-system.fig` into Figma.
