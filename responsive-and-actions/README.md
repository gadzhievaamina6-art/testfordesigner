# Responsive Behaviour and Actions

## Layouts

- Desktop frame: 1440 px
- Desktop content: up to 1200 px
- Mobile frame: 390 px
- Department cards: two columns on desktop
- Department cards: one column on mobile
- Footer contacts change to a vertical list on mobile
- The CTA button expands to the available mobile width
- The hero background is cropped on mobile
- Text and interactive elements take priority over decoration
